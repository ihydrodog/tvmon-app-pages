1. 처리하는 정보와 목적

tvmon-app은 이어보기와 즐겨찾기 기능을 위해 콘텐츠 식별 정보, 제목, 링크, 이미지 주소, 재생 위치, 수정 시각 등 기능에 필요한 데이터를 기기에 저장합니다. Google Drive 동기화를 선택하면 해당 데이터를 연결한 계정의 Drive 앱 전용 폴더에 저장하고 다른 기기의 데이터와 병합합니다.

Google 연결 시 OAuth 액세스 토큰을 사용합니다. PC 버전은 자동 갱신을 위한 refresh token과 계정 표시를 위한 이메일 정보를 기기에 저장합니다. Android 버전은 Google Play 서비스의 Authorization API로 액세스 토큰을 받아 기기에 저장합니다. 앱이 Google 비밀번호를 수집하거나 저장하지 않습니다.

2. Google Drive 접근 범위

앱은 https://www.googleapis.com/auth/drive.appdata 권한을 요청합니다. 이 권한은 숨겨진 앱 전용 데이터 폴더의 파일을 관리하기 위한 것으로, 일반 Drive 파일 전체에 대한 접근 권한은 아닙니다. PC 버전은 추가로 openid 및 email 권한을 요청합니다.

3. 저장 위치와 제공

동기화 데이터는 사용자 기기와 사용자가 연결한 Google Drive에 저장됩니다. 앱의 동기화 구현은 개발자 운영 서버에 Google 계정 정보나 동기화 데이터를 업로드하지 않습니다. 동기화 과정에서 Google API에 인증 토큰과 동기화할 데이터를 전송합니다. Google 사용자 데이터를 판매하거나 광고 목적으로 이용하지 않으며, 범용 AI·머신러닝 모델 학습에 사용하지 않습니다.

앱에서 여는 콘텐츠 사이트, 외부 이미지 및 메타데이터 서비스는 해당 요청을 처리하며 자체 개인정보처리방침이 적용됩니다. 이 소개 사이트는 GitHub Pages로 호스팅되며 별도의 분석 스크립트나 로그인 기능이 없습니다. GitHub는 호스팅 제공 과정에서 접속 IP 등 기술 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.

4. 보관과 삭제

기기 데이터는 사용자가 앱 데이터를 삭제하거나 제거하기 전까지 보관될 수 있습니다. Drive 사본은 사용자가 삭제하기 전까지 남을 수 있습니다.

  • 앱에서 로그아웃하면 앱이 저장한 Google 인증 파일을 삭제합니다. 로그아웃만으로 기기 내 시청 기록이나 Drive 사본이 삭제되지는 않습니다.
  • Google 계정의 서드 파티 연결 관리에서 앱 접근 권한을 취소할 수 있습니다. 권한 취소와 기존 Drive 데이터 삭제는 별개입니다.
  • Google Drive 설정의 앱 관리에서 해당 앱의 숨겨진 앱 데이터를 삭제할 수 있습니다.
  • 기기 내 데이터를 모두 제거하려면 운영체제의 앱 데이터 삭제 기능을 사용하거나 앱 데이터 폴더와 웹뷰 저장소를 삭제하세요. 기기와 클라우드 사본을 모두 지우려면 연결된 각 기기 데이터도 삭제해야 합니다.

5. Google 사용자 데이터의 제한적 사용

tvmon-app의 Google API에서 받은 정보 사용 및 다른 앱으로의 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다. Google 사용자 데이터는 사용자가 요청한 계정 연결과 동기화 기능 제공에 사용합니다.

6. 선택권과 보안

Google 연결은 선택 사항이며 언제든 중단할 수 있습니다. Google API 통신에는 HTTPS를 사용합니다. 인증 정보는 기기 내 앱 데이터 영역에 저장되므로 기기와 계정의 접근 권한을 안전하게 관리하세요.
